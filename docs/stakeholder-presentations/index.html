LiveWire Portal

The single one-place-to-go location for all your tools and applications. WordPress front-end with Kerberos SSO, embedded chat, file sharing, webmail, and multi-site high availability.

Executive Summary

The problem: Teams bounce between separate portals, chat, mail, file shares, and tool links. That fragmentation slows work, weakens security posture, and makes multi-site operations fragile.

The answer: LiveWire Portal is one unified front door. Everything your people need — SSO, chat, files, webmail, and deep links to every internal tool — lives behind a single, themed, authenticated experience.

Why it matters

  • Lower operational cost — one platform to maintain instead of a stack of point solutions.
  • Stronger security — Kerberos SSO, consistent access, fewer exposed endpoints.
  • Better collaboration — chat and file sharing embedded where people already work.
  • Resilient by design — multi-site HA across three locations with load balancing and failover.

Scale targets

Built for three sites on different subnets, load-balanced and fail-over ready, running on an XCP-ng pool managed through Xen Orchestra.

Bottom line

One portal, one login, one place to go. Consolidation with clear security and resilience upside — ready for leadership review.

Features & Benefits

A complete collaboration and access layer surfaced through a single, consistent interface.

Core capabilities

  • SSO Kerberos / SPNEGO authentication against FreeIPA or Active Directory.
  • Chat Embedded XMPP via Converse.js and Prosody.
  • Files Upload, download, and sharing built into the portal.
  • Webmail Roundcube embedded for mail without leaving the portal.
  • Tool links Consistent themed links to every internal application.
  • Multi-site HA Three locations, different subnets, load balance plus failover.
  • XCP-ng Runs on a virtualization pool managed by Xen Orchestra.

Benefits of the single-pane approach

  • No context-switching — chat, mail, files, and tools are one click away.
  • One theme and one login across every surface.
  • Helpdesk and users share the same front door, reducing ticket volume.
  • HA and failover are part of the design, not an afterthought.

Technical Build

Architecture: WordPress as the front-end, Apache with Kerberos/SPNEGO, Prosody for XMPP, Roundcube for webmail, HAProxy plus Keepalived for multi-site load balancing and failover, all on an XCP-ng pool.

Stack

  • Front-end: WordPress + livewire-child theme
  • Auth: Apache mod_auth_kerb / SPNEGO against FreeIPA or AD
  • Chat: Converse.js (client) + Prosody (XMPP server)
  • Mail: Roundcube embed
  • Files: portal-native sharing
  • HA: HAProxy + Keepalived across three sites
  • Hypervisor: XCP-ng pool with Xen Orchestra
  • Custom: livewire-shortcodes plugin
